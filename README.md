# Log Workspace

A browser-based tool for reading and working with logs.

- Format JSON and XML, and convert between them.
- Turn compact log bodies into readable vertical text.
- Compare two logs and see changed values.
- Create a simple report with separate Request, Response, and Callback sections.
- Copy or download results.

All log processing happens in the browser. The app does not upload logs, save them in browser storage, or send them to a server. Passwords, IDs, and other values are displayed as provided.

## Use the website

The site is plain HTML, CSS, and JavaScript. No build step or external service is required.

For GitHub Pages, select **Settings → Pages → Deploy from a branch → main → / (root)** and save.
